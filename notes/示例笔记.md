# 个人知识库示例

这是一个用于冒烟测试的示例笔记，用来验证检索链路是否正常。

## eino 是什么

eino 是 CloudWeGo 开源的 Go 语言大模型应用开发框架，核心能力包括：
- 统一的组件抽象（ChatModel、Embedding、Indexer、Retriever、Loader 等）
- 图编排（compose）与 React 智能体（adk）
- 回调与流式处理能力

框架源码在本机 `d:/GoWork/src/eino`，文档位于 cloudwego.io。

## 知识库是怎么工作的

建库流程：加载 Markdown → 按标题切块 → Embedding → 写入 Redis 向量索引。
问答流程：问题向量化 → Redis 检索 Top-K 片段 → ChatModelAgent 基于片段作答。
